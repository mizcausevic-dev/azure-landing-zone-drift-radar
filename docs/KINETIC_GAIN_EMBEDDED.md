# Kinetic Gain Embedded tie-back

This repo demonstrates the Azure platform-governance control-plane shape of Kinetic Gain Embedded:

- landing-zone baseline visibility
- management-group policy inheritance drift
- owner-role and privilege-path cleanup
- network perimeter and route-integrity posture
- diagnostics and Defender coverage evidence

For embedded product work, the same primitive becomes an in-app Azure platform-governance panel where operators need evidence-rich surfaces without direct access to raw Azure portals or tenant credentials.
